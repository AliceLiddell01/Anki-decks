KanjiVG reference data attribution
=================================

The compressed Unicode-addressed mask catalog in this directory is derived
from KanjiVG SVG stroke data.

The generated catalog contains 6,430 CJK templates. Each source SVG was
rasterized with the pinned `resvg` dependency, converted to a binary foreground
mask, and normalized with the shared `normalize_binary_mask` routine. The
routine crops foreground bounds, aspect-fits within 56x56, centers the mask in a
64x64 canvas, then samples nearest-neighbor pixels from source-cell centers:
`floor((2 * output_index + 1) * source_size / (2 * output_size))`. This is
adapted data; the generated catalog is provided under CC BY-SA 3.0.

To regenerate from the pinned release archive, extract its `kanji/` directory
and run from the workspace root:

  cargo run --locked -p asset-store --features reference-generator \
    --bin build-kanjivg-reference -- \
    --source-dir /path/to/kanjivg/kanji \
    --output tools/asset-store/src/data/kanjivg-r20250816.maskdb.zlib

The generated output hash must match the value above.
