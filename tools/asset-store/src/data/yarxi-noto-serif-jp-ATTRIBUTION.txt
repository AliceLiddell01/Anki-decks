Yarxi Noto Serif JP reference data attribution
==============================================

The compressed Unicode-addressed mask catalog in this directory is derived
from rendered glyphs in the Noto Serif JP font served by Yarxi:

  https://www.yarxi.su/fonts/noto-serif-jp.24fc2d26.ttf

Source TTF SHA-256:
  e6cffcd5cae6a298ddfd17173b42d64888913976b2d7053024a9ecf0cf5d3fe8

Font metadata identifies the family as Noto Serif JP, PostScript name
NotoSerifJP, version 1.001. The Noto CJK upstream identifies releases before
version 1.002 as Apache License 2.0:

  https://github.com/notofonts/noto-cjk/blob/main/Serif/README-third_party.md
  https://www.apache.org/licenses/LICENSE-2.0

Noto Serif CJK was developed by Adobe and Google. The upstream history and
current project metadata are available at:

  https://github.com/notofonts/noto-cjk/blob/main/Serif/HISTORY.md
  https://github.com/google/fonts/tree/main/ofl/notoserifjp

This repository does not redistribute the TTF. The generated catalog contains
6,428 normalized 64x64 binary glyph masks for the Unicode characters also
present in the pinned KanjiVG catalog. `build_yarxi_font_reference.rs` checks
the source TTF hash before generating these masks with the locked `resvg`
dependency.

Generated file: yarxi-noto-serif-jp-r1.maskdb.zlib
Generated file SHA-256:
  a3a9b1e6c49c89b747e9fe1551425776662e80c670ba19f8daa4160f72733024

To regenerate, obtain the Yarxi source font above and run from the workspace root:

  cargo run --locked -p asset-store --features reference-generator \
    --bin build-yarxi-font-reference -- \
    --font-file ./NotoSerifJP.ttf \
    --output tools/asset-store/src/data/yarxi-noto-serif-jp-r1.maskdb.zlib

The source hash is checked by the generator and the compressed output hash must
match the value above.
